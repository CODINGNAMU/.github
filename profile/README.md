## 🗂️ 목차

|  순서 |         알고리즘        |         학습 내용        |
| :-: | :-----------------: | :------------------: |
|  01 |         Hash        |  해시를 활용한 데이터 탐색 및 관리 |
|  02 |    Stack / Queue    |   스택과 큐를 활용한 문제 해결   |
|  03 |         Heap        |    우선순위 큐와 힙 자료구조    |

|  06 |        Greedy       | 현재의 최적 선택을 이용한 문제 해결 |
|  07 | Dynamic Programming |  중복되는 부분 문제를 활용한 최적화 |
|  08 |      DFS / BFS      |  깊이 우선 탐색과 너비 우선 탐색  |
|  09 |    Binary Search    |  이분 탐색을 활용한 효율적인 탐색  |
|  10 |        Graph        |   그래프 탐색 및 그래프 알고리즘  |
